# Marevita Marine Private Ltd - Business Website

## Project Overview
This is the official business website for **Marevita Marine Private Ltd**, a marine services company. The website will showcase the company's services, expertise, and provide a professional online presence.

## Project Structure

```
/
```

## Tech Stack

### Core Technologies
- **React.js** - JavaScript library for building the UI
- **Tailwind CSS** - Utility-first CSS framework for styling
- **JavaScript** - No TypeScript; use vanilla JavaScript throughout
- **Vite** - Modern, fast build tool and development server
- **React Router** - Client-side routing for multi-page navigation

### Forms & Email
- **Contact Forms** - Implement contact form functionality
- **Email Integration** - Set up email service for form submissions (e.g., EmailJS, Formspree, or similar)

### Animation & Visual Enhancement
- **Framer Motion** - For smooth, professional animations and transitions
- Use animations sparingly to enhance user experience without overwhelming

### Icons
- **Lucide React** or **React Icons** - Choose based on design needs; prefer Lucide for cleaner, modern icons

### Additional Libraries
- Standard React (client-side rendering)
- No backend services required
- Form validation and handling to be implemented

## Design Guidelines

### ⚠️ IMPORTANT: Avoid Generic AI Design Patterns
- Do NOT use generic, template-like designs commonly generated by AI tools
- Create professional, distinctive UI that reflects the marine services industry
- Focus on premium, bespoke design elements
- Avoid overused patterns like generic hero sections, cookie-cutter cards, or standard AI website layouts
- Think about what makes a high-end professional services website stand out

### Design Approach
1. Review all design references in the `references/` folder first
2. Check the sample content screenshots in `content/` folder
3. Use custom fonts from `assets/fonts/` for brand consistency
4. Create a unique visual identity appropriate for a marine services company
5. Prioritize professional aesthetics over trendy web design patterns

## Content
- Sample content and screenshots are available in the `content/` folder
- Use these as guidance for the type of content the website will feature

## Development Notes
- This is a business-critical website - quality and professionalism are paramount
- The design should convey trust, expertise, and premium marine services
- Mobile responsiveness is essential
- Performance and accessibility should be considered

## Visual Design
- The website should use a distinctive black-and-white alternating section design.
- Sections should transition using bold, organic, irregular wavy dividers rather than straight horizontal lines.
- The dividers should have an expressive, custom silhouette with varying heights, curves, and occasional sharper bends—similar to an abstract coastline or fluid contour.
- Avoid perfectly smooth, symmetrical sine-wave patterns or generic decorative waves. Each section transition should feel intentionally designed and visually distinctive.

When beginning work on this project:

4. Plan the website structure and pages needed
